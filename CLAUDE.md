# Questland Adventures — workspace guide

Pitch-ready mobile PWA for the Questland adventure park. App code lives in `questland/`.

## Stack
React 19 + TypeScript + Vite + vite-plugin-pwa. react-router v7. No CSS framework — DS tokens mirrored to `questland/src/theme/ds/*.css` (dark-first stone + gold-as-metal, from `design-system/`); `theme/tokens.css` is a BRIDGE keeping old var names (--parchment/--ink/--gold/--forest/--arcane/--ember + -soft) pointed at DS values. Fonts via @fontsource (bundled, offline PWA), icons via lucide-react. Local-first service layer (`questland/src/services/`, localStorage-backed) mirrors Firestore collections so Firebase can swap in later; components never touch localStorage directly. All lore/content is data in `questland/src/content/*.ts` — placeholder lore until user material lands in `content-intake/`.

## Commands
- Dev server: `npm run dev` in `questland/` (PWA enabled in dev)
- Build: `npm run build` · Icons: `npm run icons`
- Node installed at machine level; refresh PATH in PowerShell sessions if `node` not found.

## Design system (CANON — mirrored in design-system/, source DesignSync id fd4a099b-4d30-456b-92fa-c7d33afaf0dd)
Read `design-system/readme.md` before any UI work. Non-negotiables: **dark-first** stone ground (parchment = documents only: tickets/maps/scrolls, via Card tone="parchment"); gold = metal, primary actions only (never flat fills, never on parchment); ruby/sapphire = narrative track colors only; type Cinzel (display, ALL CAPS tracked, <6 words) / EB Garamond (body) / Alegreya Sans (UI, only face <14px) / IM Fell English (scribe, max 2 lines); radii 2/4/6/10 + signature top **arch**; hairline gold borders; carve-in shadows; motion mechanical (160ms standard, 720ms door-ease reveals, fade+8-12px rise, no bounce/spring); hover lightens, press darkens+down; locked = dashed hairline + kept arch shape, never 40% opacity; focus ring 2px gold. **NO EMOJI ANYWHERE** — Lucide icons (lucide-react) per readme's glyph vocabulary; brand marks are raster assets, never redrawn. Naming: ticket=Passage, group=Party, reward=Seal, achievement=Badge, stop=Station, route=Questline, staff=Guide/Warden. Voice: warm ceremonious guild, second person, concrete numbers, no "immersive/unforgettable", ≤1 exclamation per page. DS components (jsx+d.ts) in design-system/components; app screen proposals in design-system/ui_kits/app (TrailMap, StationCheckIn, Collection, Party) — adapt, don't ignore. UI brief (pre-DS, superseded where they conflict): `design/claude-design-brief.md`.
